# Currach whirligig v3, interactive viewer

A three.js model of a 450 mm flat currach weather vane with three articulated rowers. A propeller at the bow drives a
24:1 worm, a crank and a link bar that works the oars. Version 3 adds a magnetic slip clutch so the propeller
freewheels in a gale.

Open the page, drag to orbit, scroll to zoom. The wind slider sets propeller rpm and stroke rate; the magnet gap slider
sets the wind at which the clutch lets go. Switch between flat 45 degree blades and the twisted 60 to 28 degree set,
or cut the hull away to see the worm and wheel.

`index.html` and `parts.glb` are generated from the design files; edit those, not these.
